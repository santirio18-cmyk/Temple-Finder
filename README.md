# Temple Finder (Phase 1)

This repository contains the **Temple Finder** web application: a Vite + React + TypeScript app under [`temple-finder/`](temple-finder/).

## Quick start

```bash
cd temple-finder
npm install
npm run dev
```

See [`temple-finder/README.md`](temple-finder/README.md) for environment variables, Vercel deployment, and project details.

## Vercel

Set the project **Root Directory** to `temple-finder` when importing this repo.
